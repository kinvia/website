# Kinvia Website

Este es el sitio web estático de Kinvia.

## Desarrollo Local

Puedes levantar un servidor de desarrollo local para probar el sitio web y los cambios de idioma utilizando `npx` (Node.js) o `python3`.

### Opción 1: Usando `npx` (Recomendado)
Ejecuta el siguiente comando desde este directorio:
```bash
npx -y http-server -p 8080
```

### Opción 2: Usando Python
Ejecuta el siguiente comando desde este directorio:
```bash
python3 -m http.server 8080
```

Una vez iniciado el servidor, abre [http://localhost:8080](http://localhost:8080) en tu navegador para ver la página web.

## Idiomas Soportados
La web soporta los siguientes idiomas dinámicamente:
- **ES**: Español
- **EN**: Inglés
- **DE**: Alemán
- **DA**: Danés
